# Project Gallery

A single page that links all eighty projects, each with a live demo and its own repository.

## Features

- All eighty projects in one searchable grid
- Filter by category: Games, Creative, Tools, Productivity, Learning, Reference and Web
- Direct links to every live demo and source repository
- Live result count and an empty state
- Press `/` anywhere to jump to the search box

## Projects

The gallery covers every build in the collection, from the games and drawing tools to the weather app, quiz bank and periodic table.

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    project data, rendering and filtering
```

## Tech

Plain HTML, CSS and JavaScript.
